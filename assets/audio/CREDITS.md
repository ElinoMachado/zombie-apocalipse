### Zumbis (autor do jogo)
- `female-zombie-idle.mp3`, `male-zombie-idle.mp3` — vagando
- `zombie-attacking-1.mp3` … `zombie-attacking-4.mp3` — perseguição

Coloque ficheiros em `public/assets/audio/` (ou `src/audio/`) com **idle** ou **attacking** no nome.

Depois execute `npm run sync:audio` (ou `npm run dev`, que sincroniza automaticamente).
